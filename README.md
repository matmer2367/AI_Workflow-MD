# AI Workflow Rules

General-purpose workflow rules for AI-assisted software development projects, including early alignment on the user's big-picture project goals.

## How to use
1. Copy the contents of this repository's `AI_WORKFLOW_RULES.md` into the rules filename your assistant supports (for example, `.github/copilot-instructions.md`, `AGENTS.md`, or `WORKFLOW_RULES.md`).
2. Tell your AI assistant to use that target file as the project workflow/rules source.
3. Adjust sections to match your repository conventions, tooling, and release process.
